# Insta Social AI

SaaS para Instagram, YouTube e cortes de vídeo com IA.

## Stack
Next.js App Router, TypeScript, Supabase Auth, Vercel; worker Railway na próxima fase.

## Iniciar
1. `npm install`
2. Copie `.env.example` para `.env.local` e configure Supabase.
3. `npm run dev`

## Segurança
Nunca envie chaves secretas para o GitHub. Configure variáveis no ambiente de deploy.
